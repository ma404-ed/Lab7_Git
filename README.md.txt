# Temperature Converter

## Project Purpose
The Temperature Converter is a simple Python program that converts temperatures between Celsius and Fahrenheit. It helps users understand temperature conversion using basic Python programming.

## How to Run the Program
1. Install Python on your computer.
2. Open the terminal in the project folder.
3. Run the following command:

```bash
python temperature_converter.py
```

## Example Input and Output

**Example 1: Celsius to Fahrenheit**

Input:
```text
Enter temperature in Celsius: 25
```

Output:
```text
Temperature in Fahrenheit: 77.0
```

**Example 2: Fahrenheit to Celsius**

Input:
```text
Enter temperature in Fahrenheit: 98.6
```

Output:
```text
Temperature in Celsius: 37.0
```

## Temperature Conversion Formulas

- Celsius to Fahrenheit: (C × 9/5) + 32
- Fahrenheit to Celsius: (F − 32) × 5/9
